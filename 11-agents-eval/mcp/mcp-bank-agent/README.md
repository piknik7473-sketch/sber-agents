# MCP Bank Agent Server

MCP сервер для банковского агента с инструментами поиска продуктов, конвертации валют и расчета доходности вкладов.

## 📋 Описание

Этот MCP сервер предоставляет пять инструментов для расширения возможностей банковского агента:

1. **search_products** - поиск актуальных продуктов банка (вклады, кредиты, карты, счета)
2. **currency_converter** - конвертация валют по актуальным курсам ЦБ РФ
3. **deposit_income_calculator** - расчет доходности вклада с учетом капитализации и налогов
4. **open_deposit** - открытие депозитного счета (вклада) с подтверждением через HITL
5. **open_credit_card** - открытие дебетовой/кредитной карты с подтверждением через HITL

## 🛠 Инструменты

### 1. search_products

Универсальный поиск актуальных банковских продуктов с гибкой фильтрацией.

**Параметры:**
- `product_type` - тип продукта: `deposit`, `credit`, `debit_card`, `credit_card`, `account`
- `keyword` - ключевое слово для поиска в названии и описании
- `min_amount` - минимальная сумма (ищет продукты доступные от этой суммы)
- `max_amount` - максимальная сумма (ищет продукты доступные до этой суммы)
- `min_rate` - минимальная процентная ставка
- `max_rate` - максимальная процентная ставка
- `currency` - валюта продукта: `RUB`, `USD`, `EUR`

**Примеры использования:**

```python
# Найти все вклады
search_products(product_type="deposit")

# Найти вклады с ставкой от 15%
search_products(product_type="deposit", min_rate=15.0)

# Найти кредиты до 1 млн рублей
search_products(product_type="credit", max_amount=1000000)

# Найти продукты с кешбэком
search_products(keyword="кешбэк")

# Найти кредитные карты с беспроцентным периодом
search_products(product_type="credit_card", keyword="без %")
```

**Что возвращает:**
Форматированный список найденных продуктов (топ-10) с полной информацией:
- Название и описание
- Процентная ставка (для вкладов и кредитов)
- Диапазон сумм
- Срок
- Особенности продукта

### 2. currency_converter

Конвертация валют по актуальным курсам ЦБ РФ с поддержкой всех основных валют.

**Параметры:**
- `from_currency` - исходная валюта: `RUB`, `USD`, `EUR`, `CNY`, `GBP`, `CHF`, `JPY`, `TRY`
- `to_currency` - целевая валюта: `RUB`, `USD`, `EUR`, `CNY`, `GBP`, `CHF`, `JPY`, `TRY`
- `amount` - сумма для конвертации (опционально, если не указана - вернется только курс)

**Примеры использования:**

```python
# Узнать курс доллара к рублю
currency_converter(from_currency="USD", to_currency="RUB")

# Конвертировать 100 долларов в рубли
currency_converter(from_currency="USD", to_currency="RUB", amount=100)

# Конвертировать 1000 рублей в евро
currency_converter(from_currency="RUB", to_currency="EUR", amount=1000)

# Конвертировать доллары в евро (через рубли)
currency_converter(from_currency="USD", to_currency="EUR", amount=100)
```

**Что возвращает:**
- Результат конвертации с указанием суммы (если amount указан)
- Текущий курс валют
- Обратный курс для справки

**Источник данных:** API ЦБ РФ (https://www.cbr-xml-daily.ru/latest.js)

### 3. deposit_income_calculator

Расчет доходности вклада с учетом простого или сложного процента и опциональных налогов.

**Параметры:**
- `amount` - сумма вклада в рублях (обязательный)
- `rate` - процентная ставка годовых (обязательный)
- `term_months` - срок вклада в месяцах (обязательный)
- `calculation_type` - тип расчета: `simple` (простой процент) или `compound` (с капитализацией), по умолчанию `simple`
- `capitalization_months` - период капитализации: `1`, `3`, `6`, `12` месяцев (только для compound), по умолчанию `1`
- `include_tax` - учитывать НДФЛ 13% на доход свыше 150,000₽, по умолчанию `false`
- `detailed` - детализированный расчет с помесячной разбивкой (только для compound), по умолчанию `false`

**Примеры использования:**

```python
# Простой расчет без капитализации
deposit_income_calculator(amount=500000, rate=16, term_months=12)

# С капитализацией каждый месяц
deposit_income_calculator(
    amount=500000, 
    rate=16, 
    term_months=12, 
    calculation_type="compound"
)

# С капитализацией раз в квартал и учетом налогов
deposit_income_calculator(
    amount=1000000,
    rate=14,
    term_months=24,
    calculation_type="compound",
    capitalization_months=3,
    include_tax=True
)

# Детальный расчет с разбивкой по периодам
deposit_income_calculator(
    amount=300000,
    rate=15,
    term_months=12,
    calculation_type="compound",
    detailed=True
)
```

**Что возвращает:**
- Начальная сумма, ставка, срок
- Тип расчета (с капитализацией или без)
- Доход
- Налог (если include_tax=True)
- Чистый доход (после налогов)
- Итоговая сумма
- Помесячная разбивка (если detailed=True для compound)

**Особенности:**
- Простой процент: доход = сумма * ставка * (месяцы / 12)
- Сложный процент: проценты начисляются с учетом предыдущих начислений
- Налог: 13% на доход свыше 150,000₽ согласно законодательству РФ
- Агент уточняет недостающие параметры у пользователя перед вызовом

### 4. open_deposit

Открытие депозитного счета (вклада) для клиента.

⚠️ **КРИТИЧНАЯ ОПЕРАЦИЯ** - требует подтверждения через Human-in-the-Loop (HITL)

**Параметры:**
- `deposit_name` - название депозита (обязательный): `Пополняй`, `Сохраняй`, `Управляй`
- `amount` - сумма вклада в рублях (обязательный, от 1000₽)
- `term_months` - срок вклада в месяцах (обязательный, от 1 до 60)

**Примеры использования:**

```python
# Открыть вклад Пополняй на 500 тысяч на год
open_deposit(deposit_name="Пополняй", amount=500000, term_months=12)

# Открыть вклад Сохраняй на 2 года
open_deposit(deposit_name="Сохраняй", amount=1000000, term_months=24)
```

**Что возвращает:**
- Номер счета (20 цифр, начинается с 42301810)
- Название и банк
- Условия вклада (сумма, ставка, срок)
- Даты открытия и окончания
- Прогноз доходности (простой процент)
- Статус активации

**Поток HITL:**
1. Агент получает запрос от пользователя
2. Агент останавливается и показывает кнопки "Подтвердить" / "Отклонить"
3. Пользователь принимает решение
4. Если одобрено - вклад открывается
5. Если отклонено - операция отменяется

### 5. open_credit_card

Открытие новой дебетовой или кредитной карты для клиента.

⚠️ **КРИТИЧНАЯ ОПЕРАЦИЯ** - требует подтверждения через Human-in-the-Loop (HITL)

**Параметры:**
- `card_type` - тип карты (обязательный): `debit` (дебетовая) или `credit` (кредитная)
- `client_name` - имя владельца латиницей (обязательный, 3-26 символов)

**Примеры использования:**

```python
# Открыть дебетовую карту
open_credit_card(card_type="debit", client_name="IVAN PETROV")

# Открыть кредитную карту
open_credit_card(card_type="credit", client_name="MARIA KOZLOVA")
```

**Что возвращает:**
- Номер карты (замаскирован для безопасности)
- Тип карты
- Платежная система (Visa/Mastercard/МИР)
- Срок действия
- Владелец карты
- Статус активации
- Примечание о CVV (отправляется отдельно через СМС)

**Особенности:**
- CVV код НЕ возвращается в ответе (безопасность)
- Имя на карте автоматически приводится к верхнему регистру
- Срок действия: 3 года с текущей даты

## 🎯 Разделение ответственности инструментов

### rag_search (из основного агента)
- Статические документы банка (PDF)
- Общие правила и условия
- Инструкции и политики
- Исторические данные

### search_products (этот MCP сервер)
- Актуальные продукты банка
- Текущие ставки и условия
- Доступные предложения
- Динамические данные

### currency_converter (этот MCP сервер)
- Курсы валют в реальном времени
- Конвертация между валютами
- Актуальные данные ЦБ РФ

### deposit_income_calculator (этот MCP сервер)
- Расчет доходности вкладов
- Простой и сложный процент
- Учет капитализации и налогов
- Прогнозирование дохода

## 🔄 Обновление данных

**Продукты банка:**
Обновляются вручную через редактирование `data/bank_products.json`.

**Курсы валют:**
Обновляются автоматически при каждом вызове `currency_converter` через API ЦБ РФ.
