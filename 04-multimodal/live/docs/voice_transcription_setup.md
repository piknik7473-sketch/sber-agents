# Настройка транскрибации голосовых сообщений

## Обзор

Бот поддерживает транскрибацию голосовых сообщений с использованием OpenAI Whisper. Голосовые сообщения автоматически распознаются и обрабатываются как обычные текстовые сообщения.

## Требования

1. **Python зависимости**: `openai-whisper` (уже добавлена в `pyproject.toml`)
2. **Системные зависимости**: 
   - `ffmpeg` (для обработки аудио)
   - GPU (рекомендуется) или мощный CPU для быстрой обработки

## Установка на сервере

### 1. Установка системных зависимостей

```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install -y ffmpeg

# Проверка установки
ffmpeg -version
```

### 2. Установка Python зависимостей

```bash
cd live
uv sync
# или
pip install openai-whisper
```

### 3. Настройка переменных окружения

Добавьте в файл `.env`:

```bash
# Настройки Whisper для транскрибации голосовых сообщений
WHISPER_MODEL=base          # tiny, base, small, medium, large (рекомендуется: base)
WHISPER_LANGUAGE=ru         # ru, en, auto и т.д.
```

**Рекомендации по выбору модели:**
- `tiny` - самая быстрая, но менее точная (~39MB)
- `base` - хороший баланс скорости и точности (~74MB) ⭐ **Рекомендуется**
- `small` - лучше точность, медленнее (~244MB)
- `medium` - высокая точность (~769MB)
- `large` - максимальная точность, очень медленная (~1550MB)

**Примечание**: Модель загружается автоматически при первом использовании.

## Использование

После установки бот автоматически обрабатывает голосовые сообщения:

1. Пользователь отправляет голосовое сообщение в бот
2. Бот транскрибирует его в текст
3. Распознанный текст отправляется пользователю
4. Текст обрабатывается как обычное сообщение (извлечение транзакций и т.д.)

## Ограничения

- Максимальная длина голосового сообщения: **60 секунд** (для быстрой обработки)
- Первая загрузка модели может занять время (зависит от размера модели)
- Обработка может быть медленной на CPU (рекомендуется GPU)

## Производительность

Примерное время обработки на GPU (RTX 4090):
- `base` модель: ~1-3 секунды для 10-секундного сообщения
- `small` модель: ~2-5 секунд для 10-секундного сообщения

На CPU обработка может занять в 5-10 раз больше времени.

## Устранение неполадок

### Ошибка: "No module named 'whisper'"
```bash
pip install openai-whisper
# или
uv sync
```

### Ошибка: "ffmpeg not found"
```bash
sudo apt-get install ffmpeg
```

### Медленная обработка
- Используйте модель `tiny` или `base` вместо `large`
- Убедитесь, что используется GPU (если доступен)
- Уменьшите максимальную длину сообщения

### Ошибка загрузки модели
- Проверьте подключение к интернету (модель загружается автоматически)
- Проверьте свободное место на диске
- Попробуйте использовать меньшую модель
